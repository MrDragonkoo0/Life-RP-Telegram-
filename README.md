# Life+ RP v0.1 — Етап 1: карта та рух

Це перший браузерний прототип на Phaser 3 з наданими текстурами.

## Запуск
1. Розпакуй ZIP.
2. Відкрий папку `LifePlusRP_v0.1_stage1`.
3. Запусти локальний HTTP-сервер у цій папці (не відкривай `index.html` напряму, бо браузер може заблокувати завантаження PNG).
4. Відкрий адресу сервера у браузері.

Якщо є Python:
- Windows: `python -m http.server 8000`
- Android/Pydroid 3: у терміналі Pydroid з папки проєкту виконай `python -m http.server 8000`
- Потім відкрий `http://127.0.0.1:8000`

Phaser завантажується з CDN, тому для запуску потрібен інтернет.

## Керування
- Телефон: джойстик унизу ліворуч, кнопки «БІГ» і «ВЗАЄМОДІЯ» праворуч.
- Комп'ютер: WASD або стрілки; Shift — біг; E — поки зарезервовано.

## Що входить
- Місто-прототип із дорогами, тротуарами, будинками, деревами та зоною вокзалу.
- Рух персонажа та камера, що слідує за ним.
- Чоловіча й жіноча текстури з архіву користувача.
- Текстура джойстика з архіву користувача.
- Тимчасове локальне запам'ятовування вибору статі через `localStorage` (`lifeplus_gender`: `male` або `female`).

## Межі цього етапу
Це лише локальний прототип. Реєстрації Telegram, пароля, серверної частини та бази даних тут ще немає. Після тесту руху й відображення персонажа виправимо помилки, перш ніж переходити до наступного етапу.


## v0.1.1 — повноекранний режим і горизонтальна орієнтація
- Додано кнопку «На весь екран». Натискання також просить браузер/Telegram розгорнути гру та за можливості зафіксувати горизонтальну орієнтацію.
- У вертикальному режимі показується підказка повернути телефон.
- Ігрове поле масштабується, щоб заповнювати екран; на дуже широких екранах краї сцени можуть трохи обрізатися.
- Важливо: автоматичний поворот і повний екран залежать від підтримки Telegram/браузера та можуть вимагати натискання кнопки.

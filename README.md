# Life+ RP — Telegram Bot

**Версія:** v0.1.0  
**Статус:** початковий код підготовлено, потрібно додати в GitHub і протестувати 😅  
**Платформа:** Telegram  
**Технології:** Python, aiogram 3, PostgreSQL, Railway

## Що реалізовано в коді v0.1.0
- `/start` — початок реєстрації або показ профілю наявного гравця.
- Введення імені у форматі `Dragon_Bondarenko`.
- Інлайн-кнопки підтвердження та зміни імені.
- Профіль: рівень, XP і гроші.
- `/profile` — перегляд профілю.
- `/admin` — кількість гравців (доступ лише для заданого ADMIN_ID).
- Збереження гравців у PostgreSQL.

## Налаштування Railway
Додай у Variables:
- `BOT_TOKEN` — токен від BotFather.
- `DATABASE_URL` — URL PostgreSQL від бази Railway.

Запускова команда: `python bot.py`

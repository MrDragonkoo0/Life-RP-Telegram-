# Life+ RP v0.1.0 Text MMO
Перший етап текстової MMO RP-гри для Telegram Mini App.

Реєстрація: нікнейм, ім'я персонажа, стать, пароль, підтвердження пароля.
Після реєстрації: ₴1000, рівень 1. Локація не додається.

Це демо-клієнтської реєстрації. Для фінальної версії потрібні серверна реєстрація, перевірка Telegram initData, хешування пароля та база даних.

# Life+ RP v0.1.1 — Велика карта

У цій версії додано велику ігрову карту Life+ RP.

## Карта
- 6144×4096 ігрових координат.
- Велике центральне місто.
- Житлові та промислові райони.
- Вокзал і залізниця.
- Порт, пляжі та море.
- Аеропорт.
- Села, поля та ферми.
- Ліси, річки, озера та мости.
- Гори та кар'єр.
- Шосе, міські дороги та кільцеві розв'язки.

## Керування
- Телефон: джойстик унизу ліворуч, «БІГ» праворуч.
- Комп'ютер: WASD або стрілки; Shift — біг.
- Джойстик має окремі текстури для напрямків: idle / up / down / left / right.

## Важливо
Карта зараз підключена як великий ігровий світ. Колізії з конкретними дорогами, будинками, водою та іншими об'єктами будуть окремим етапом, щоб не ламати рух персонажа.

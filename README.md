# Life+ RP — Text MMO v0.1.1

Оновлення v0.1.1: базові механіки Text MMO.

## Додано
- персонаж: рівень, XP, HP, гроші;
- роботи з 12 рівнями та оплатою;
- 33 бізнеси;
- 4 класи автосалонів: Економ, Стандарт, Преміум, Люкс;
- купівля/продаж бізнесу;
- баланс бізнесу та накопичення прибутку;
- забір прибутку власником;
- купівля автомобілів через автосалон;
- гроші за продаж авто надходять на баланс автосалону;
- транспорт гравця;
- список гравців (демо);
- профіль із рівнем, XP та HP.

## Важливо
Ця версія працює як клієнтський прототип і зберігає дані в localStorage. Для справжньої взаємодії всіх гравців, реальних власників бізнесів і синхронних платежів потрібен сервер та PostgreSQL/Railway.

# Life+ RP v0.1.0 — Text MMO

Перший етап розробки текстової MMO RP-гри для Telegram Mini App.

## Що є у v0.1.0

- Реєстрація персонажа.
- Нікнейм.
- Ім'я персонажа.
- Вибір статі.
- Пароль та підтвердження пароля.
- Отримання Telegram ID у Telegram WebApp.
- Початковий баланс: **₴1 000**.
- Початковий рівень: **1**.
- Збереження демо-профілю у `localStorage`.
- Відображення створеного профілю після реєстрації.
- Адаптивний інтерфейс для телефона.

## Поточний статус

Це клієнтська версія v0.1.0. Реальної серверної авторизації та бази даних поки немає.

Для наступного етапу потрібні:

1. Backend.
2. PostgreSQL / Railway.
3. Серверна реєстрація.
4. Перевірка Telegram `initData` на сервері.
5. Безпечне хешування пароля.
6. Збереження ігрового профілю в базі даних.
